# fatherbot

Bộ não thứ hai (second brain) của Namcuba, xây theo bài "Claude Second Brain & Folder Workflow" của @Bober_smart: các file Markdown phẳng cùng một bản đồ `CLAUDE.md`.

## Cấu trúc
- `CLAUDE.md`: bản đồ điều hướng và quy tắc, Claude Code tự đọc khi khởi động
- `notes/`: kiến thức, mỗi chủ đề một file
- `people/`: thẻ người và tổ chức
- `projects/`: dự án gồm trạng thái, đang dừng ở đâu, bước tiếp theo
- `MEMORY.md`: bối cảnh cốt lõi
- `LEARNINGS.md`: bài học
- `decisions.md`: nhật ký quyết định

## Sử dụng
Clone repo về, mở terminal trong thư mục và chạy `claude`.
